Sobre mim

Formação e atuação em desenvolvimento web

Sou estudante de Engenharia de Software e desenvolvedor de soluções web, com foco na construção de interfaces funcionais e bem estruturadas.

Minha atuação envolve o desenvolvimento de sites institucionais, landing pages e sistemas personalizados, buscando unir organização de código, legibilidade visual e boa experiência de uso em diferentes dispositivos.

Tenho interesse contínuo em desenvolvimento de sistemas, arquitetura de interfaces e boas práticas de engenharia de software aplicadas ao front-end.

Habilidades

Tecnologias e aplicação prática

Competências organizadas por categoria e contextualizadas conforme seu papel no desenvolvimento web. Nesta V1 acadêmica, utilizo exclusivamente HTML5, CSS3 e JavaScript Vanilla.

Fundamentos Web

  • HTML5 Estruturação semântica de documentos, hierarquia de cabeçalhos e base acessível.
  • CSS3 Estilização modular com variáveis, Flexbox, Grid, transições discretas e responsividade.
  • JavaScript Lógica no navegador, manipulação do DOM e organização modular em ES6+.

Ecossistema & Tipagem

  • TypeScript Tipagem estática aplicada para maior previsibilidade e manutenção em projetos web.
  • React Construção de interfaces componentizadas e gerenciamento de estado no cliente.
  • Next.js Estruturação de aplicações web com roteamento e estratégias modernas de renderização.

Versionamento & Fluxo

  • Git / GitHub Controle de versão, preservação de marcos históricos e organização de repositórios.
